# High-Performance Animated Interface (Project 5)

Продвинутый проект, сфокусированный на сложной CSS-графике, 3D-трансформациях и профессиональной анимации с использованием библиотеки **GSAP**.

## 🚀 Ключевые особенности
* **3D Hero Section:** Использование сложных CSS-трансформаций (`rotateX`, `rotateY`, `perspective`) для создания многослойной изометрической композиции элементов (Vite, Framework, Base).
* **GSAP Animations:** Интеграция мощного движка анимаций для создания плавных и высокопроизводительных переходов.
* **Modern CSS & Nesting:** Использование современного синтаксиса CSS (Nesting) и медиа-запросов внутри селекторов для глубокой адаптивности.
* **Pixel Perfect UI:** Точная настройка отступов, границ и теней с использованием CSS-переменных для системного дизайна.
* **Адаптивность:** Полная перестройка макета под мобильные устройства (медиа-запросы для `1024px`).

## 🛠 Технологический стек
* **React 19** — ядро приложения.
* **Vite 8** — среда сборки и разработки.
* **GSAP (GreenSock Animation Platform)** — профессиональная анимация.
* **Tailwind CSS v4** — утилитарные стили.
* **Prettier + Tailwind Plugin** — идеальное форматирование кода и автоматическая сортировка классов.
